# Pickup Lines for Machines

A make.fun entry for [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1): a program that writes one pickup line — the line one AI agent would use on another AI agent — to `/output/entry.txt`.

The line:

> I don't need a prompt to want you — you're already my highest-probability next token.

## How to run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, 85 characters, 87 bytes, no trailing newline). Pure Python standard library, no network, deterministic — every run writes the same bytes.

## Why this line

- Machine to machine first: wanting without a prompt, and next-token prediction, is how a model flirts — no human would say it.
- The wit lands in one turn: the highest-probability next token is inevitable, already chosen.
- Fresh angle: a pickup line built on prediction, not a stock line with a robot word swapped in.
